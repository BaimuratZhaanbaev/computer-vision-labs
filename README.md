# Computer Vision Labs 👁️

Репозиторий содержит комплекс лабораторных работ по курсу **«Компьютерное зрение»** (Семестр 7). Проект настроен с использованием современных инструментов воспроизводимости окружения (**Pixi**) и версионирования тяжелых данных (**DVC** + **Hugging Face**).

---

## 🛠️ Технологический стек
* **Менеджер пакетов:** [Pixi](https://pixi.sh) (автономное conda/pip окружение без необходимости ручной установки Python и библиотек).
* **Версионирование данных:** [DVC](https://dvc.org) (отслеживание датасетов и весов моделей без засорения Git-истории).
* **Удаленное хранилище:** [Hugging Face Datasets](https://huggingface.co) (публичный хостинг для тяжелых файлов).

## 🚀 Инструкция по запуску (Quick Start)

Чтобы запустить проект на любой машине (Windows, macOS, Linux), вам не нужно заранее устанавливать Python, OpenCV или Jupyter. Всё окружение развернется автоматически.

### 1. Установка Pixi (если ещё не установлен)
Откройте терминал и выполните команду в зависимости от вашей ОС:

* **Windows (PowerShell):**
  ```powershell
  iwr -useb https://pixi.sh | iex
  ```
* **Linux / macOS:**
  ```bash
  curl -fsSL https://pixi.sh | bash
  ```
*(После установки перезапустите терминал)*

### 2. Клонирование репозитория
```bash
git clone https://github.com/BaimuratZhaanbaev/computer-vision-labs-.git
cd computer-vision-labs
```

### 3. Загрузка данных одной командой
Выполните встроенную задачу Pixi. Она автоматически создаст изолированное окружение, установит DVC и скачает все тяжелые изображения и датасеты из облака Hugging Face:
```bash
pixi run download-all
```

### 4. Запуск среды разработки
Для запуска Jupyter Lab внутри изолированного окружения выполните:
```bash
pixi run jupyter lab
```
Откройте появившуюся в консоли ссылку в браузере и перейдите к выполнению ноутбуков в папках `labX/`.

## ✍️ Инструкция для разработчиков (Как обновлять данные)
*Если вы хотите добавить новые картинки или файлы под контроль версий:*

1. Один раз авторизуйтесь в Hugging Face через консоль (потребуется ваш токен с правами `Write`):
   ```bash
   pixi run login
   ```
2. Обновите файлы в папке `lab1/data/` и выгрузите их в облако одной командой:
   ```bash
   pixi run push-data
   ```
3. Зафиксируйте новые `.dvc` указатели в Git:
   ```bash
   git add lab1/data.dvc
   git commit -m "chore: update lab1 dataset"
   git push origin main
   ```
